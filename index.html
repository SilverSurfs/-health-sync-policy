Health Sync

Homepage and privacy policy · last updated 20 November 2026

What this is

Health Sync is a private, single-user script. It reads the developer's own fitness data from the Google Health API and saves it to notes on the developer's own computer. It is not a public service, and no one else can sign up or use it.

Privacy policy

  • Data accessed: read-only activity and fitness, sleep, and health-metric data for the single Google account that owns this app.
  • How it is used: only to produce personal summaries (for example, daily steps and sleep) for that same person.
  • Storage: data is stored only on the owner's own devices. It is not uploaded to any server run by this app.
  • Sharing: data is never sold, shared with third parties, or used for advertising.
  • Write access: none. The app only requests read-only permissions.
  • Revoking access: access can be removed at any time from Google Account → Third-party connections.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
